CloudOS extension settings

Configure the URL the new-tab page opens, and opt into the optional history bridge.

CloudOS URL

The new-tab page will redirect (or embed) this address. Self-hosted, localhost, or your hosted instance — whatever you point it at.

Browser history bridge

Lets the AI Assistant's /recent slash command pull from your real browser history (last 7 days, up to 50 entries by default) when you're viewing CloudOS at the configured URL above. Off by default — turning this on grants that origin read-access to your browsing history through this extension.
